# Stage 1 — Write the Python file

## Task

Create `hello.py` in the repo root with a minimal, runnable Python 3 script.

## Acceptance criteria

- File exists at `hello.py`.
- File is valid Python 3 (no syntax errors).
- Running the file produces visible output (e.g. a printed message).

## Example content

```python
def main():
    print("Hello, world!")

if __name__ == "__main__":
    main()
```

Exact content is up to the agent; the above is the floor, not the ceiling.
